# Moon — сайт студии красоты

Многостраничный статический сайт для студии красоты Moon (Минск, район метро Михалово). Чистые HTML, CSS и JavaScript, без сборки.

## Страницы
- `index.html` — главная
- `services.html` — услуги и цены
- `studio.html` — о студии, фото интерьера
- `contacts.html` — Instagram, запись, карта

## Структура
`style.css`, `main.js` (меню и плавное появление), иконки `favicon*` и `apple-touch-icon.png`, фото в `images/`.

## Запуск
`python3 -m http.server 8000` и открыть http://localhost:8000

## GitHub Pages
Загрузите содержимое папки в корень репозитория, затем Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что нужно уточнить и дописать
- **Точный адрес и телефон** — пока на сайте только район метро Михалово и Instagram. Добавьте их в `contacts.html` и в футер каждой страницы.
- **Карта** — маркер стоит по координатам из ссылки на Яндекс Карты, проверьте, что он на нужном доме.
- **Цены** — указаны женские стрижки из прайса в Instagram. Для остальных услуг замените `<span class="pr ask">цену уточняйте</span>` на `<span class="pr">45 Br</span>`.
- **Время работы** — не указано.
- **Цвета** — переменные в начале `style.css`. Шрифты: Unbounded и Onest (Google Fonts).
